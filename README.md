# Night City 24

Wake the fuck up, samurai. Black chrome TUI for **Equibop / Equicord / Vencord** — Night City black, cyan `#55ead4`, neon yellow `#fcee0a`, neon red `#c5003c`.

One CSS file. Paste a link or drop it in Themes. No scripts, no builds, no other packages.

Repo: [TinorNoah/nightcity24](https://github.com/TinorNoah/nightcity24). Built on [refact0r/system24](https://github.com/refact0r/system24).

## Install (link)

Settings → Themes → Online Themes / Theme Links → paste:

```text
https://raw.githubusercontent.com/TinorNoah/nightcity24/main/nightcity24.theme.css
```

Enable **Night City 24** only. Do **not** also enable Midnight, system24, or Private Channel Recolor — Night City already includes system24 + lock recolor, and stacking themes makes Equibop sluggish.

## Install (file)

1. Download [`nightcity24.theme.css`](https://raw.githubusercontent.com/TinorNoah/nightcity24/main/nightcity24.theme.css)
2. Put it in your themes folder:

| OS | Path |
| --- | --- |
| macOS | `~/Library/Application Support/equibop/themes` |
| Windows | `%APPDATA%\equibop\themes` |
| Linux | `~/.config/equibop/themes` |

3. Themes → Local → enable **Night City 24**

## What’s inside

- Night City black panels (`#000000`)
- Cyan icons (`#55ead4`); neon yellow for labels, unfocused chrome, muted text (`#fcee0a`)
- Neon red for links, mentions, unread/jump, brand focus only (`#c5003c`)
- Equibop UI fixes (header gap, labels, Quick Switcher, …)
- Private-channel lock recolor
- Custom splash: **NIGHTCITY** ASCII + *WAKE THE FUCK UP, SAMURAI*
- Home/DMs terminal glyph
- Stream / Go Live fit fixes
