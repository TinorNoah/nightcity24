# system24 (cyberpunk)

One-file Equibop / Equicord theme. **No install scripts. No Equicord build. No other packages.**

Includes:

- system24 base (via `@import`)
- Cyberpunk black backgrounds
- Neon red accents / hovers (`#FF003C`)
- Teal icons (`#39c4b6`) + cyan links (`#54c1e6`)
- Yellow channel categories (`#F3E600`)
- Equibop UI fixes (header gap, labels, Quick Switcher, etc.)
- Private channel lock recolor (adapted from [KrstlSkll69/vc-snippets](https://github.com/KrstlSkll69/vc-snippets))

## Install with a link (recommended)

1. Fully quit and reopen Equibop/Equicord after adding if it does not refresh live.
2. Open **Settings → Themes → Online Themes** (or Theme Links).
3. Paste this URL and enable the theme:

```text
https://raw.githubusercontent.com/TinorNoah/system24-cyberpunk-theme/main/system24-cyberpunk.theme.css
```

4. Turn **off** any older system24 / catppuccin online theme and the separate “Private Channel recolor” snippet if you used those before (they are already in this file).

## Install as a local file

1. Download [`system24-cyberpunk.theme.css`](https://raw.githubusercontent.com/TinorNoah/system24-cyberpunk-theme/main/system24-cyberpunk.theme.css).
2. Put it in your client’s `themes` folder:

| OS | Themes folder |
| --- | --- |
| macOS | `~/Library/Application Support/equibop/themes` |
| Windows | `%APPDATA%\equibop\themes` |
| Linux | `~/.config/equibop/themes` |

3. Settings → Themes → Local → enable **system24 (cyberpunk)**.

## File

```
system24-cyberpunk.theme.css
```

That is the whole theme.
